Engine 01 · Historical Intelligence

🚀PROCESS

"Eight seasons of NFL tape, compressed into 115 features the box score never captured."

How it works

  • Ingest eight seasons of play-by-play, PFF grades, and next-gen tracking. 300K+ plays, 43,564 player-games.
  • Engineer 115 process features across five layers — every calculator measures how a stat was generated, not what stat was generated.
  • Train ensemble models per position and stat type. Poisson for scoring events. Regression for volume. All gated by a constitutional checker.
  • Constitutional rule: no feature can be a historical average of the stat being predicted. The constraint makes backtests worse and real prediction better.

Feature Architecture (5 Layers)

L1 Context
Game script, weather, rest days, travel, short-week penalties. Situational scaffolding.
L2 Vegas
Implied totals, spreads, line movement. A market consensus we use as a prior — then try to beat.
L3 Team Process
EPA per dropback, success rate, neutral pace, pass-over-expected. How teams generate value.
L4 Tracking
Air yards, separation, pressure rate, time-to-throw. What the body-cams actually saw.
L5 Player Process
Route participation, yards per route run, targets per route run, pressure evasion. Usage-normalized.

Engine 02 · Who's Rolling This Week

📊FORM

"Last four games weigh more than last four seasons. Injuries land in the model before they land on Twitter."

How it works

  • Pull six live streams in parallel — NFL play-by-play, PFF grades, Vegas lines, injury reports, weather, tracking data.
  • Weight by recency. Exponential decay: the last 4 games carry 3× the weight of games 5–8. Games from 2 seasons ago barely move the needle.
  • Form deltas, not raw numbers. We don't re-predict from recent data — we compute a delta that nudges the ML baseline. Keeps the 8-year foundation intact.
  • Injury cascade. When a starter drops, downstream snap-share and target-share shift within minutes — no human touch required.

Engine 03 · Adversarial Simulation

♞CHESS

"Two LLM coordinators, a QB agent, and a statistical resolver — calling real plays at each other, snap by snap, a thousand times."

How it works

  • LLM agents carry real tendencies. OC prompts are built from career play-call distributions: Shanahan's outside zone rate, Reid's RPO rate, red-zone splits, down-and-distance personnel.
  • Snap sequence: OC calls play → DC calls coverage → QB reads and optionally audibles → resolver computes outcome statistically.
  • The resolver is math, not a coin flip. Calibrated on 300K+ real plays, it samples from the conditional distribution P(yards | play, coverage, personnel, field position, time). <5ms per play.
  • 1,000 runs = distribution. Each sim produces a box score. 1,000 sims produce a full probability distribution per player — not a point estimate.
  • Feedback loop: simulation surfaces weird features humans wouldn't engineer. Those features re-enter the prediction model. The model improves the simulator.

Agent Roster

OC AgentOffense
Offensive coordinator persona. Picks personnel, formation, play call from situation and tendencies.
"Heavy box. Running it into a light front."
DC AgentDefense
Defensive coordinator persona. Calls coverage and pressure based on down, distance, personnel grouping.
"Cover 2, bracket WR1. Don't let Z get behind us."
QB AgentField General
Pre-snap read and audible logic. Can override OC's call if the coverage is obvious.
"Single-high, blitz coming. Hot route to the slot."
ResolverStatistical
Calibrated conditional sampler. Inputs: all four prior calls + game state. Output: yards, EPA, TD flag.
